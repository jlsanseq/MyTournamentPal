# Milestones

## Milestone 0: Representación del dominio

En este milestone se usará la metodología de DDD para desarrollar un PMV donde se tenga un modelado del dominio en base a las Historias de Usuario y que nos permita trabajar sobre el problema en siguientes milestones. Se trabajará principalmente sobre la [HU001](historias_usuario.md#hu001-no-se-a-que-me-voy-a-enfrentar) como punto de partida.

La validez se comprobará observando si se ha seguido correctamente la metodología en base al dominio del problema.

## Milestone 1: Simulación básica

En este milestone se busca desarrollar un PMV donde comenzar a implantar una lógica de negocio que permita avanzar hacia la resolución de las historias de usuario planteadas en [historias_usuario.md](historias_usuario.md) partiendo de lo desarrollado en el Milestone 0. 

El producto será válidado haciendo uso de tests, que comprobaran si la lógica desarrollada funciona correctamente de forma automática.
